## ✨ Features

- 🌗 **Dark / Light Mode** — theme toggle with localStorage persistence
- ⌨️ **Typing Animation** — dynamic role text in hero section
- ✨ **Cursor Sparkle Trail** — custom cursor with glowing particle trail
- ⭐ **Particle Background** — floating animated stars in hero
- 🃏 **3D Card Tilt** — perspective tilt effect on hover
- 📊 **Animated Skill Bars** — progress bars animate on scroll
- 📜 **Page Loader** — smooth loading animation on open
- ⬆️ **Back to Top** — floating button appears on scroll
- 🍔 **Hamburger Menu** — mobile-friendly navigation
- 🔗 **Active Nav Highlight** — current section highlighted on scroll
- 📄 **Resume Download** — direct PDF download button
- 📱 **Fully Responsive** — works on all screen sizes
